# AI Personal Assistant Projects

A collection of AI-powered personal-assistant tools by **Naman Pathak** ([namanpathak503@gmail.com](mailto:namanpathak503@gmail.com)).

## Projects

| Project | What it is |
|---|---|
| [**FormPilot**](formpilot/) | Chrome / Brave extension that fills web forms with AI, grounded in your own documents. Suggestions appear right under the field, like a password manager. Supports Gemini, Chrome built-in AI, OpenRouter, Groq, Ollama and any OpenAI-compatible endpoint. |

Each project lives in its own folder with its own README, setup steps and tests.
